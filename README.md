
# Book and Movie Recommender

## Project Overview
A simple academic project that recommends books and movies using content-based filtering.

## Problem Statement
Users have many books and movies to choose from. This project aims to help users discover relevant content based on item features and user preferences.

## Initial Approach
The first baseline will represent content using text features such as genre and description, then rank items using cosine similarity.

## Project Scope
- A shared catalog for books and movies
- Python implementation
- Reproducible data preparation and evaluation
- Academic prototype; not a production recommendation service

## Repository Structure
- `data/raw/`: source data, excluded from Git by default
- `data/processed/`: generated data, excluded from Git by default
- `notebooks/`: exploratory analysis
- `src/`: reusable project code
- `tests/`: tests
- `reports/`: project reports
